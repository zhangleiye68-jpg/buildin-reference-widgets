# 本地翻页时钟

固定入口：<https://zhangleiye68-jpg.github.io/buildin-reference-widgets/school-planner/flip-clock/>

默认保留原有本地24小时、时分秒翻页和日期。可选 `locale=ru-RU&show_date=0&fit=1&labels=1` 隐藏日期、适配窄栏并显示“Часы / Минуты / Секунды”单位标签；`labels` 省略时维持旧的无标签显示。`background` 和 `dark_background` 接受URL编码的六位HEX色值，分别配置系统深浅背景。

无倒数、账号或数据库连接；读取访客本地时间，不写本地保存。174px与161px真实窄栏已验证时分秒、标签和秒推进。

通用带标签预览：[PNG](../../catalog/previews/flip-clock-ru-units.png)。
