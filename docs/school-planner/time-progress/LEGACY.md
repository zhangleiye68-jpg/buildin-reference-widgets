# 可配置俄语时间进度

入口 `legacy.html` 独立于现有默认进度组件，旧地址算法不变。此入口使用访客浏览器本地日期，每五秒刷新，无账号或数据库连接。

参数 `bars` 是按显示顺序排列的 `year,month,week,day,quarter,life` 子集；`color`、`dark_color`、`background` 为 HEX 色值，`theme=system` 跟随系统文字配色。`decimals` 是百分比小数位，默认零位。`lifespan` 仅用于源模板已配置的人生进度；生日使用地址末尾片段 `#birth=YYYY-MM-DD`，由客户端读取，不放进 HTTP 查询或本地存储。公开预览只用通用示例，不推断为用户生日。

兼容算法有意保留：周从周一开始、周和日只累计到分钟；月使用包含今天的日期号；年使用当年第几天除以 365，闰年末可能超过 100%；季度使用首尾日序差；人生使用实际已过毫秒除以一天，再除以 `365×寿命 + trunc(寿命/4)`。标签使用 `toFixed` 舍入，条形边界限制在 0–100%。这与现有连续时间进度入口不同。

独立实现常规日历数学与显示，不复制或分发第三方服务源码、账号配置、私人实例 URL 或记录。人生日期保存在使用者提供的 URL 中，不保存到本地存储。
