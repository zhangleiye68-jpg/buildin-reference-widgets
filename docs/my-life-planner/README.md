# My Life Planner widgets

Production files migrated from our existing My Life Planner widget site on 2026-11-03. The existing Russian interface, animations, controls, media, and local-storage keys are preserved.

Use stable GitHub Pages URLs under `https://zhangleiye68-jpg.github.io/buildin-reference-widgets/my-life-planner/`:

- `clock.html` — flip clock
- `pomodoro.html` — focus timer
- `counter.html` — reading counter
- `plant.html` — plant watering
- `animal.html` — animated animal scene
- `music.html` — music and ambience
- `cover.html` — animated garden cover

Counts and preferences are stored in the viewer's browser. No user state is committed to this repository. The original deployment configuration and provider metadata are excluded.
