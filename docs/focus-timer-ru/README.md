# 俄语专注倒计时

稳定入口：<https://zhangleiye68-jpg.github.io/buildin-reference-widgets/focus-timer-ru/>

独立编写的通用计时器，默认 60 秒。五个预设为 1、15、30、60、120 分钟；Старт 开始，Пауза 暂停，Продолжить 继续，Сброс 回到当前所选预设。点击数字区域也可开始或暂停。选择预设会停止计时并重设时长。结束停在零，可重新开始，不自动进入下一轮。

按单调时钟截止时刻计算剩余时长，切回后台后按经过的时间刷新。无声音、通知、远程请求、账号、本地保存或 Buildin 数据库同步。刷新页面回到默认 60 秒，不能迁移第三方服务的运行状态或账号配置。默认展示无个人数据。

建议高度 400px；适配 161–600px 宽度，窄栏按钮自动分行。所有按钮支持键盘操作，状态为俄语。此入口无需任何参数；未知参数不影响行为。

可选 `accent` 和 `surface` 接受 URL 编码的六位 HEX 色值，用于主色和按钮底色；默认值分别为 `#e9bd98`、`#e9e9e9`。不读取或执行第三方服务的配置。
